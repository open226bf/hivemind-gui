Secrets & configs

Le rattachement se fait depuis le formulaire du service ; cet onglet règle comment chaque fichier est exposé dans les conteneurs. Un propriétaire vide laisse le choix à l'orchestrateur (root) et un mode vide vaut 0444. Les identifiants doivent être numériques : le runtime ne résout pas les noms d'utilisateur. Les modifications s'appliquent au prochain déploiement.

Secrets

Swarm monte toujours les secrets sous /run/secrets/ : seul le nom de fichier du chemin ci-dessous est retenu. Un chemin /etc/app/db.pwd aboutit donc à /run/secrets/db.pwd.
